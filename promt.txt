2. PROJECT GOAL

Create a Telegram-controlled service that:

1. Receives commands from a Telegram bot.
2. Uses Telethon user authentication to access Telegram channels.
3. Searches channels for documents.
4. Processes ONLY .txt files.
5. Accepts files from 10 MiB through 4 GiB.
6. Downloads files to disk instead of RAM.
7. Uploads them to TeraBox.
8. Deletes the local temporary file after successful upload.
9. Provides job status and cancellation.
10. Runs continuously on Render.
11. Uses GitHub as the source repository.
12. Supports automatic Render deployment after GitHub changes.

11. LARGE FILE HANDLING

This is extremely important.

The service must support files up to 4 GiB.

NEVER load a complete 4 GiB file into RAM.

Do not use full-memory buffering.

Use a disk-based temporary file.

Default:

DOWNLOAD_DIR=/tmp/tg_downloads

Make DOWNLOAD_DIR configurable.

Before downloading:

1. Determine file size.
2. Check available disk space.
3. Require additional safety margin.
4. Download to disk.

RAM consumption must remain relatively small regardless of file size.
